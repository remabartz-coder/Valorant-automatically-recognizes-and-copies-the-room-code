# QueuePilot Icon

An original Q monogram in the application's charcoal, white and emerald colors.
The icon is covered by the project's MIT license and contains no third-party marks.

`queuepilot.ico` contains 16, 20, 24, 32, 40, 48, 64, 128 and 256 pixel PNG entries.
`queuepilot.png` is the transparent 256 pixel version used by Qt and the README.

To regenerate both on Windows (no additional packages):

```powershell
./scripts/generate-icon.ps1
```
