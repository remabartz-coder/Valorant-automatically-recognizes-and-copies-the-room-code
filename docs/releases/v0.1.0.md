# QueuePilot v0.1.0

首个公开 Windows x64 便携版本，从直播、媒体流、本地视频或窗口画面识别无畏契约房间码，确认后复制到剪贴板并语音提示。

## 下载与启动

- `QueuePilot-Windows-x64-v0.1.0.zip`：Windows 10 1903+ / Windows 11 x64 可运行包，包含运行库、OCR 模型、许可证及依赖对应源码。完整解压后运行 `QueuePilot.exe`，不要只提取 EXE。
- `QueuePilot-corresponding-sources-v0.1.0.zip`：Qt、FFmpeg 对应源码、构建记录和第三方声明，便于独立下载查阅。
- `SHA256SUMS-v0.1.0.txt`：两个压缩包的 SHA-256 校验值。

GitHub 自动生成的 `Source code` 归档是项目源码，不是 Windows 可运行包。

## 功能

- 支持抖音直播页解析、媒体地址解码、本地视频与窗口采集。
- 本地 OCR、自动定位、手动框选与选区锁定，支持带边距和周围文字的区域。
- 房间码由三个 ASCII 大写字母和三个数字组成；可限定为字母在前、数字在后。不自动替换 `I/1`、`O/0`。
- 多帧确认后自动复制并异步语音播报，程序后台或最小化时继续处理。
- 可选 F8 游戏填入及单次自动填入，默认不发送 Enter；提供停止热键。
- 全新桌面界面和应用图标。

## 已验证与限制

发布工作流在 Windows 运行器构建并运行自动测试，再检查完整便携包能启动和生成测试画面。测试禁用真实剪贴板、语音及游戏按键输出；本地另有用户截图和录屏回归记录，见 `docs/VALIDATION.md`。

直播页面变化、登录要求或未开播可能使地址解析失败。识别速度不包含平台直播延迟，不保证抢队成功率。窗口采集是否持续更新取决于目标窗口；国服游戏的实际输入兼容性仍需实机验证。

项目采用 MIT；Qt、FFmpeg、ONNX Runtime 和模型分别遵循各自许可证，详见包内 `THIRD_PARTY_NOTICES.md`。
